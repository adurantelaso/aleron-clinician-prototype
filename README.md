# Aleron MD · Clinician workspace (prototype)

A clickable prototype of the Aleron MD reviewing-clinician workspace: dashboard, notes, orders, lab results and care plans.

**Live:** https://adurantelaso.github.io/aleron-clinician-prototype/

Everything here is fictional. The patients, results and orders are generated demo data, and nothing is sent anywhere: orders, Junction fulfillment and lab results are simulated. Your clicks are saved only in your own browser; **Test scenarios → Reset demo** starts over.

This repository holds only the built site (published with GitHub Pages). The source lives in the `clinician-workspace` app of the orders-and-notes project.
