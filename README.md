# Aleron MD · Clinician workspace (prototype)

A clickable prototype of the Aleron MD reviewing-clinician workspace, set up as the Notes and Orders demo for one patient, Ethan Park. It opens on Journey 1, creating and finalizing a new note; add `?journey=2` to the address for Journey 2, creating and authorizing a new order.

**Live:** https://adurantelaso.github.io/aleron-clinician-prototype/

Everything here is fictional. The patients, results and orders are generated demo data, and nothing is sent anywhere: orders, Junction fulfillment and lab results are simulated. Your clicks are saved only in your own browser; **Reset demo** in the left rail starts over.

This repository holds only the built site (published with GitHub Pages). The source lives in the `clinician-workspace` app of the orders-and-notes project.
